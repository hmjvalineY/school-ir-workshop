# 校務研究研習・互動實作

高中校務研究系列研習的互動網頁。**簡報講觀念，這裡動手做**：遇到實作、操作、實驗、示範時，從簡報上的連結或 QR Code 進來；練習用的髒資料、對照表與解答都可以在網站上下載。

🌐 網站：<https://hmjvaliney.github.io/school-ir-workshop/>

> 所有資料皆為研習用模擬資料：姓名已遮罩、地址以○代替、網域為 example.edu.tw，不含任何真實學生個資。網頁上的運算全部在瀏覽器裡完成，不會上傳任何資料。

## 講授時怎麼用

- 每個實作頁標題下方都標示「簡報：第 N 張」，簡報的「互動連結版」在對應頁面放了連結與 QR Code。
- 快速鍵：`P` 投影模式（放大字級）、`Q` 顯示本頁 QR Code 給學員掃、`F` 全螢幕、`← →` 同一場的上／下一個實作。
- 學員要自己操作時，按 `Q` 投出 QR Code；資料下載頁有每一場的打包檔。

## 專案結構

```
materials/            研習素材（下載檔的來源，版控）
  s0/  開場 50 問：講義 PDF、50 題資料
  s1/  第一場：模擬校務資料、講義 A–D、範例儀表板
  s2/  第二場：練習資料（五個系統的髒資料）、解答、講義 E–F
  s3/  第三場：治理研習髒資料、去識別化練習、解答（由 gen_governance_data.py 產生）
scripts/
  build_site_data.py      materials → site/data/*.json ＋ site/downloads/（打包 zip）
  gen_governance_data.py  產生第三場的練習資料（固定亂數種子）
  check_site.py           部署前檢查連結與目錄
site/                 靜態網站（GitHub Pages 發布的內容）
  index.html  downloads.html
  assets/css/site.css  assets/js/common.js（目錄、頁首工具、共用函式）
  s0/ s1/ s2/ s3/       各場次的互動頁
.github/workflows/pages.yml   推送到 main 後自動建置並部署
```

## 更新內容

1. 換練習資料：把新檔放進 `materials/` 對應資料夾（檔名不變），推送到 GitHub 即可，Actions 會自動重新打包並部署。
2. 新增實作頁：在 `site/sN/` 新增 HTML，並把它加進 `site/assets/js/common.js` 的 `SESSIONS` 目錄（`check_site.py` 會檢查兩邊是否一致）。
3. 本機預覽：

```bash
pip install -r requirements.txt
python scripts/build_site_data.py
python -m http.server 8000 --directory site
```

然後開啟 <http://localhost:8000>。
